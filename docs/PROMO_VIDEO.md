Файл: [`assets/promo-video.html`](./assets/promo-video.html) — также доступен на сайте: `/promo-video.html`

### Сценарий (10 сек)

## Как добавить озвучку

Самый простой способ — **CapCut** (бесплатно, есть на телефоне и Windows).

### Шаги в CapCut
1. **Новый проект** → импортируй `promo-10s.webm` (или 6s).
2. **Аудио** → **Запись** (или **Текст → Озвучка** для AI-голоса).
3. Прочитай текст ниже вслух **по таймингу** кадров (или вставь AI-озвучку).
4. При необходимости добавь **Музыка** → «Без авторских прав» → тихий фон (−20 dB).
5. **Экспорт** → 1080p, 9:16 → сохрани **MP4** (удобнее для Telegram).

### Текст озвучки — 10 сек

| Время | Говоришь |
|-------|----------|
| 0–2 с | «EatSave — умный холодильник в Telegram» |
| 2–4 с | «Сканируешь чек — продукты сами попадают в холодильник» |
| 4–6 с | «Приложение напомнит, что скоро испортится» |
| 6–8 с | «А AI подскажет, что приготовить из того, что есть» |
| 8–10 с | «Открой бота EatSavehelper в Telegram» |

**Короткая версия (6 сек):**
> «EatSave в Telegram: сканируй чеки, следи за сроками, готовь из того что есть. EatSavehelper bot.»

### Другие программы
- **DaVinci Resolve** — бесплатно, профессионально (ПК)
- **Clipchamp** — встроен в Windows 11
- **Telegram** — можно записать голосовое и наложить в CapCut поверх видео

### AI-голос (если не хочешь записывать сам)
В CapCut: **Текст → Озвучка** — вставь текст из таблицы, выбери русский голос.
Или: [ElevenLabs](https://elevenlabs.io), [Speechify](https://speechify.com) — экспорт MP3 → импорт в CapCut на дорожку «Аудио».
